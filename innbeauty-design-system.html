01 — Positioning

Two signals held in tension

The brand has to read as clinically credible and physically soft at the same time. Charcoal, all-caps Helvetica, ratings to two decimal places and ingredient counts do the first job. A light didone display face, blush photography and warm neutral bands do the second. The whole visual language is that tension — a rebuild should not resolve it in either direction.

03 — Typography

Serif is feeling. Sans is fact.

Serif appears only on emotive display lines and section titles. Every functional string — navigation, buttons, product names, prices, badges, footer — is Helvetica Neue, most of it uppercase. This split is the single rule that defines the brand.

RoleFamilyStackWeights
DisplayIvy Presto Headline Light'Ivy Presto Light', serif200, 200 italic
Display altivypresto-display (Typekit)"ivypresto-display", serif400
UI & bodyHelvetica Neue'Helvetica Neue', Arial, sans-serif400, 500, 600, 700

The root sets html { font-size: 10px }, so 1rem = 10px throughout. Inherited theme rules are in rem; the brand layer is in px. Specimens below are set in Bodoni Moda, a high-contrast didone standing in for Ivy Presto Headline, which is not web-licensable.

Rules

  • Uppercase is the default for anything interactive or labelling. Sentence case is reserved for prose and serif display.
  • Tracking sits near zero everywhere. The one negative value is the badge at −0.3px, tightening a 12px all-caps chip.
  • Serif never goes bold — weight 200 only. Its authority comes from size, not weight.
  • Body line-height is generous at 1.8; component text is tight at 1.15–1.35.

05 — Shape, Elevation & Motion

Square cards. No shadows. One radius.

Separation comes entirely from whitespace and background bands. Every shadow opacity token is 0.0; the one exception sits on a 0px blur and therefore renders nothing.

TokenValueApplies to
--buttons-radius4pxButtons, inputs
--badge-corner-radius4pxBadges
--card-corner-radius0pxCards are square
--media-radius0pxImagery is square
--popup-corner-radius0pxModals

4px is the only radius, and only on interactive chrome. Social icons are the single exception at border-radius: 100%. Card image hover is transform: scale(1.03), desktop only. prefers-reduced-motion is respected.

Five rules that carry the system

  1. Serif for feeling, uppercase sans for fact. Never swap them. This is the brand.
  2. Charcoal #27292B, never black. White page, dark bands as punctuation.
  3. Square cards and imagery. 4px radius on interactive chrome only.
  4. No shadows. Separation is whitespace and background colour.
  5. One accent, one primary button, per screen.

09 — Known defects

Do not faithfully reproduce these

Flagged so a rebuild inherits the system without inheriting its bugs.

Color

Pure black leaks in. Hero copy and several h2 / p blocks compute to rgb(0,0,0) instead of #27292B.

Type

h1 has line-height: 0 and renders in Helvetica at 32px/700. The real display heading is h2 in Ivy Presto — heading levels do not map to the type scale at all.

Token

#334FB4 is orphaned. An inherited theme accent that is never rendered anywhere. Not part of the brand palette.

Cascade

!important is load-bearing in the footer newsletter and waitlist buttons — specificity has been lost to app-injected markup.

Spacing

No scale exists. Eighteen distinct section and margin values with no common factor.

Fonts

Two serif faces ship for near-identical roles — self-hosted Ivy Presto Light plus Typekit ivypresto-display. One is redundant.

Dead

--card-shadow-opacity: 0.1 sits on a 0px blur — a token that does nothing.
