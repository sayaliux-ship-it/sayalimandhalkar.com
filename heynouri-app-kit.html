The site shows its product UI only as flat PNG mockups, so there was no app design to extract. These three screens are reasoned from the brand: the marketing rhythm drops from 200px to 24px, the deep-green bands become the dark theme, and the four tints stop being decoration and take fixed jobs.

Three rules these screens encode. Progress is always a ring, never a bar — there is no straight rule used for emphasis anywhere in this system, and the company's mission is literally "bend the curve down". There is no carrot on any of these screens: a screen earns one carrot action when it has one, and none of these do. And medication sits in the pastel-blue clinical register with no streaks, no carrot, and a warning rather than an error for a missed dose — the programme states medication is never required, so the UI must never imply a child is behind for not taking one.
